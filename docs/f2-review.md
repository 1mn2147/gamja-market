# F2 상품·검색 검토 기록

작성일: 2026-07-18  
대상: WBS-03.01~06 (상품, 이미지, 등록·수정·조회, 검색)

## 구현 범위

- 상품은 작성자, 사림동, 제목·설명·카테고리·원화 정수 가격, 상태와 이미지로 모델링했다. 작성자만 수정·숨김·삭제할 수 있고, 예약 상태 상품은 수정·삭제하지 못한다. 거래 도메인이 연결되면 이 잠금 상태를 거래 상태 전이가 설정한다.
- 이미지는 1~5장, 장당 5 MiB 이하로 제한하고 PNG·JPEG·WebP의 실제 바이트 시그니처를 검증한다. 선언된 MIME 타입은 신뢰하지 않으며, 바이너리와 대체 텍스트를 PostgreSQL에 저장한다.
- 공개 목록과 검색은 활성 상품만 사림동 및 설정된 인접 동 범위에서 반환한다. PostgreSQL FTS와 `pg_trgm` 인덱스, 카테고리·가격 필터, 정렬, 커서 기반 페이지네이션을 제공한다.
- 웹에 상품 피드, 검색, 상세, 등록, 내 상품, 수정·숨김 화면을 추가했다. 비로그인 쓰기 요청은 API에서 거부하고, 공개되지 않은 상품·이미지는 작성자가 아니면 조회할 수 없다.

## 검증 증적

| 구분 | 결과 |
| --- | --- |
| 데이터 | 상품·이미지 모델과 FTS/`pg_trgm` migration 적용, 사림동 seed 적용 |
| API 통합 | 등록·검색·이미지 바이트 반환·비작성자 비공개·예약 수정 차단·숨김 검색 제외 통과 |
| 계약 | 상품 API 경로·요청 스키마를 OpenAPI에 반영하고 계약 검사 통과 |
| 웹 | 상품 등록·검색·상세·내 상품·수정 화면 타입·프로덕션 빌드 통과 |
| 접근성 | 검색·등록·내 상품·상세 화면 axe 검사 통과 |

## 확정된 서비스 기준

1. 소규모 서비스 단계에서는 PostgreSQL 바이너리 이미지 저장을 유지한다. 사진 용량·트래픽이 증가하는 시점에만 S3 호환 객체 저장소와 서명 업로드 전환을 다시 검토한다.
2. 상품 카테고리는 자유 입력으로 유지한다. 입력 길이와 서버 검증은 적용하며, 금지 품목 통제는 WBS-04 신고 기능과 WBS-07 관리자 조치에서 처리한다.

## 후속 이력

WBS-04(1:1 채팅, 신고, 차단)는 현재 진행 중이다. 구현된 계약과 아직 닫히지 않은 재연결·중복 방지·남용 제한·차단 전파 검증은 `f3-review.md`에서 관리한다.
