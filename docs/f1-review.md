# F1 계정·인증 기반 검토 기록

작성일: 2026-07-15  
대상: WBS-02.01~06 (가입, 인증, 세션, 비밀번호 재설정, 탈퇴, 행정동, 계정 화면)

## 구현 범위

- `User` 상태(`PENDING`, `ACTIVE`, `SUSPENDED`, `WITHDRAWN`), 일반 사용자/최고관리자
  역할, Argon2id 비밀번호 해시, 불투명 세션 해시와 인증 코드 해시를 PostgreSQL에
  추가했다. 비밀번호와 인증 코드 원문은 저장하거나 로그에 쓰지 않는다.
- 가입은 이메일 또는 휴대전화, 성인 확인, 연락처 소유 인증을 거친 뒤에만 활성화된다.
  테스트 환경에서만 인증 코드가 응답에 포함되며 운영 응답에는 포함하지 않는다.
- 로그인은 HttpOnly·SameSite 세션 쿠키를 사용하고, 운영 환경에서는 Secure 쿠키가
  기본이다. 반복 로그인 실패는 5회 후 15분 잠금되며, 인증된 세션은 비밀번호 재설정과
  탈퇴 시 즉시 폐기된다.
- 탈퇴 시 상태를 `WITHDRAWN`으로 변경하고, 개인정보·채팅·거래 보존 정책(탈퇴 후
  1년)을 나타내는 `retentionUntil`을 기록한다. 감사 로그도 함께 남긴다.
- 행정동과 단방향 인접 동 관계를 모델링하고, 선택 동과 인접 동만 반환하는 API를
  추가했다. 상세 주소와 좌표 필드는 모델·응답에 포함하지 않는다.
- 로그인, 가입, 연락처 인증, 비밀번호 재설정, 내 활동, 계정·탈퇴 화면을 추가했다.

## 확정된 운영·서비스 기준

1. 연락처 소유 인증은 현재 샌드박스 범위에서 테스트·개발용 어댑터로만 처리한다.
   실제 문자·이메일 발송 사업자와 비밀 관리는 실서비스 전환 승인 시 별도 연동한다.
2. 초기 서비스 행정동은 창원시 의창구 사림동 한 곳으로 제한한다. 내부 식별자는
   `KR-CH-UC-SARIM`이며, 초기 인접 동 관계는 만들지 않는다.
3. Argon2id는 소규모 웹사이트 기준으로 메모리 19 MiB, 시간 비용 2, 병렬성 1을
   사용한다. 실제 서비스 확장 또는 인증 부하 증가 전에는 배포 환경에서 다시
   측정해 조정한다.
