# F3 채팅·안전 구현 검토 기록

작성일: 2026-07-18
대상: WBS-04.01~06 (1:1 채팅, 실시간 메시지, 신고, 차단, 제재 전파)
상태: 진행중

## 구현된 범위

- 상품별 구매자·판매자 채팅방, 참여자, 메시지, 읽은 시각을 PostgreSQL 모델과
  20260718051450_chat_safety migration에 추가했다.
- 보호된 REST API로 채팅방 생성·목록·상세·메시지 전송, 사용자 차단·해제·목록,
  사용자·상품·메시지 신고와 내 신고 조회를 제공한다.
- Socket.IO chats 네임스페이스에서 불투명 세션을 확인하고, 방 입장과 메시지
  전송 시 REST 서비스와 동일한 참여자·차단 검사를 재사용한다.
- 채팅 목록·상세, 신고 접수·내역, 차단 사용자 관리 화면을 추가했다.
- OpenAPI 0.4.0에 WBS-04 REST 경로, 세션 보안, 메시지·차단·신고 입력 경계를
  반영하고 계약 테스트와 기준선 검사를 보강했다.

## 종료 전에 남은 항목

1. WBS-04.01의 읽지 않은 메시지 수를 응답·화면·테스트까지 연결한다.
2. WBS-04.02의 메시지 중복 제거, 빈도 제한, 재연결·재시도 시나리오를 API·소켓
   통합 테스트로 고정한다.
3. WBS-04.04의 반복 신고·신고 API 남용 제한과 대상별 공개 범위를 검증한다.
4. WBS-04.05의 차단 사용자 상품·기존 대화 숨김과 차단 해제 복원을 E2E로 검증한다.
5. WBS-04.06의 이용정지가 기존 세션과 이미 연결된 소켓에 즉시 전파되는지 검증한다.
6. CHAT-01~02와 SAFE-01~03 화면의 모바일·키보드·오류·비활성·접근성 상태를
   release 게이트 증적으로 남긴다.

## 판정과 다음 개발 단위

WBS-04는 기능 표면이 연결됐지만 위 종료 조건이 남아 있으므로 진행중이다.
잔여 P0 테스트와 추적을 닫은 뒤 검토중으로 전환하고, 이후 WBS-05 직거래
도메인의 상태 머신·동시 구매 제어를 진행한다. WBS-04.07 알림·이의제기는 P1로
P0 출시 판정을 차단하지 않는다.
